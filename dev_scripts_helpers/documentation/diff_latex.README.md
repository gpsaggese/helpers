# `diff_latex.py`

- Generated by `.claude/skills/readme_file.create/SKILL.md`

- **Purpose**: Typeset the differences of a LaTeX paper between two git commits
- **Input**: The main `.tex` file of the paper and the versions to compare
- **Output**: A PDF with deleted text struck through in red and added text
  underlined in blue
  - A changed figure is shown twice: old (crossed out) and new (framed)
- **When to use**: To review the changes of a paper before a commit, a PR, or a
  new submission

## Examples

- Show the changes of the last commit:
  ```bash
  > diff_latex.py --input papers/Noesis/paper.tex -l
  ```

- Show the uncommitted changes:
  ```bash
  > diff_latex.py --input papers/Noesis/paper.tex -m
  ```

- Show the changes of the branch since it diverged from `origin/master`:
  ```bash
  > diff_latex.py --input papers/Noesis/paper.tex -n
  ```

- Compare two commits and choose the output file:
  ```bash
  > diff_latex.py \
      --input papers/Noesis/paper.tex \
      --from_ref 54845e3a \
      --to_ref d9d993ea \
      --output Noesis.diff.pdf
  ```

- Generate a quick draft of the diff:
  ```bash
  > diff_latex.py --input papers/Noesis/paper.tex -m --fast
  ```

- Generate only the `.tex` diff, without Docker:
  ```bash
  > diff_latex.py \
      --input papers/Noesis/paper.tex \
      --from_ref HEAD~5 \
      --skip_action render_images \
      --skip_action compile
  ```

## Configuration and Inputs

### Command-Line Arguments

- Exactly one of `--from_ref`, `-l`, `-m`, `-b`, `-n` is required

| Argument                   | Type | Default            | Description                                         |
| :------------------------- | :--- | :----------------- | :-------------------------------------------------- |
| `-i`, `--input`            | str  | required           | Main `.tex` file (stdin is not supported)           |
| `-o`, `--output`           | str  | `<input>.diff.pdf` | Output file (stdout is not supported)               |
| `--from_ref`               | str  | `""`               | Old git commit                                      |
| `--to_ref`                 | str  | `HEAD`             | New git commit, only with `--from_ref`              |
| `-l`, `--last_commit`      | flag | false              | Compare `HEAD~1` with `HEAD`                        |
| `-m`, `--modified`         | flag | false              | Compare `HEAD` with the uncommitted changes         |
| `-b`, `--branch`           | flag | false              | Compare the tip of `origin/master` with `HEAD`      |
| `-n`, `--branch_point`     | flag | false              | Compare the branch point with `HEAD`                |
| `--latexdiff_opts`         | str  | `""`               | Extra `latexdiff` options, passed with `=`          |
| `--fast`                   | flag | false              | Skip `render_images` and run one `pdflatex` pass    |
| `--dry_run`                | flag | false              | Report the planned diff without generating it       |
| `--action`                 | str  | none               | Add an action (repeatable)                          |
| `--only_action`            | str  | none               | Run only this action (repeatable)                   |
| `--skip_action`            | str  | none               | Remove an action (repeatable)                       |
| `--all_actions`            | flag | false              | Start from all the actions                          |
| `--clear_actions`          | flag | false              | Start from no actions                               |
| `--input_files`            | list | `""`               | Accepted by the shared parser, ignored              |
| `--from_file`              | str  | `""`               | Accepted by the shared parser, ignored              |
| `--no_report_command_line` | flag | false              | Accepted by the shared parser, has no effect        |
| `-v`                       | str  | `INFO`             | Log level, also forwarded to `render_images.py`     |

- The actions are `render_images` and `compile`, and both run by default
- `--fast` skips `render_images`, even if it is selected
  - An image that is not committed becomes an "Image not rendered" box
  - Cross-references, citations, and the bibliography are not resolved
- `--only_action` cannot be combined with the other action options
- `--all_actions` and `--clear_actions` are mutually exclusive
- Pass `--latexdiff_opts` with `=`, e.g.,
  `--latexdiff_opts='--math-markup=whole'`

### Requirements

- `latexpand`, `latexdiff`, and `latexmk` (`pdflatex` with `--fast`), which are
  part of MacTeX
- Docker, for the `render_images` action
- The input file must be in a git repo and must exist in both versions
- `-b` and `-n` use the local `origin/master`, which the script does not fetch

### Limitations

- Only images included with `\includegraphics` are compared (e.g., not inline
  TikZ drawings)
- Untracked files and uncommitted changes in submodules are never compared
- Paths in `\input` are resolved from the root of the repo, as `run_latex.py`
  does
- `render_images` processes only the `.tex` files directly in the paper dir
- Only old macros defined with a one-line `\newcommand` are carried to the diff

## Output and Side Effects

### Files Created

- **PDF diff**: `--output`, or `<input>.diff.pdf` next to the input
- **`.tex` diff**: Written instead of the PDF when `compile` is skipped
  - The extension of the output file is replaced with `.tex`
- **Work dir**: `tmp.diff_latex/` at the root of the repo
  - It is recreated at each run, so do not run two diffs in the same repo at once
  - It is deleted after a successful compilation
  - It is kept if the run fails or skips `compile`: delete it by hand, since its
    file copies break the tools that search files by name
- **Log file**: `diff_latex.py.log` next to the script
- With `-m`, `git stash create` adds a dangling commit, without changing the
  working tree or the stash list

### Exit Codes

- `0`: Success, including a `--dry_run`
- `1`: Failed check or command (e.g., missing tool, unknown commit, no
  uncommitted changes, failed compilation)
- `2`: Invalid command-line arguments

### Error Handling

- If the compilation fails, the script retries with less detailed markup, in
  this order:
  - `--math-markup=off`: the changes in the equations are not marked
  - `--exclude-textcmd=textbf`: the changes in the bold text are not marked, and
    the deleted bold text can be hidden
  - Both options together
  - The `--math-markup=off` retries are skipped if `--latexdiff_opts` already
    sets `--math-markup`
- If all the retries fail, the error points to the LaTeX log in the work dir
- A missing image or an uninitialized submodule only logs a warning

## Software Architecture

### Data Flow

1. **Select**: Resolve the old and new versions from `--from_ref` / `--to_ref`
   or from an alias
2. **Export**: Use `git archive` to export each commit and its initialized
   submodules
   - Only the LaTeX support files and the paper dir of the main repo are exported
3. **Render**: Run `render_images.py` on the snapshot (optional)
4. **Flatten**: Merge the included files of each snapshot with `latexpand`
5. **Normalize images**: Name each image after the hash of its content, and limit
   the height of the changed ones
6. **Mark up**: Run `latexdiff --graphics-markup=both`, then add the macros that
   exist only in the old paper
7. **Compile**: Run `latexmk` (one `pdflatex` pass with `--fast`) in the new
   snapshot, to use the new styles
8. **Save**: Copy the result to the output file and clean up

### Key Functions

- `_select_refs()`: Map an alias or the refs to the old and new commit
- `_list_files()`: List the entries of a commit
- `_export_commit()`: Export a commit, recursing into submodules
- `_render_images()`: Render the diagrams of a snapshot in place
- `_flatten()`: Merge a paper into a single `.tex` file
- `_hash_images()`: Rename images after their content
- `_limit_height()`: Cap the height of changed images sized only by `width`
- `_add_old_macros()`: Add `\providecommand` for the macros of the old preamble
- `_mark_up()`: Generate the `.tex` diff
- `_compile()`: Build the PDF and return whether it succeeded
- `_diff_latex()`: Orchestrate the whole workflow
- `_main()`: Parse the arguments, select the actions, and call `_diff_latex()`

### Design Patterns

- **Pipeline**: Each stage reads and writes files in the work dir
- **Isolated snapshots**: The sources in the working tree are not modified
- **Content addressing**: `latexdiff` compares only text, so a changed image
  needs a different file name to be detected
- **No `latexdiff --flatten`**: It fails on macros like `\input{#2}`, so
  `latexpand` is used instead
- **Fresh run dir**: `render_images.py` caches by file path, so a new path forces
  the figures to be regenerated
