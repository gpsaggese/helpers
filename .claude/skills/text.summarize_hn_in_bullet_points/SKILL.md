# Goal
- Summarize a Hacker News discussion for a given topic
- Follow the bullet point formatting rules in `.claude/skills/text.rules.md`

# Workflow

## Read the Input
- Given a HackerNews discussion URL, e.g.,
  `https://news.ycombinator.com/item?id=47743628`

## Summarize the Article
- Summarize the main article in 5 bullet points
  ```markdown
  # The peril of laziness lost
  - ...
  - ...
  ```

## Summarize the Comments
- Analyze the HN comment section for the linked article
- Summarize the 5 most interesting comments, favoring those that are:
  - Thought-provoking or insightful
  - Unique perspective or uncommon knowledge
  - Sparking discussion or debate
  - Technically informative or educational
  - Controversial but well-argued
- Do not print the commenter's name
- Skip simple jokes or memes, very short reactions, and repetitive or low-effort
  comments

## Write the Output
- Do not output any comment on screen
- Output the result in `hn.txt`, without bold or other markdown formatting
- Say in `hn.txt` how it was generated, with this first line, without backticks:
  ```
  Generated by .claude/skills/text.summarize_hn_in_bullet_points/SKILL.md
  ```
- Run:
  ```bash
  > lint_text.py -i hn.txt
  ```
- Run:
  ```bash
  > cat hn.txt
  ```
