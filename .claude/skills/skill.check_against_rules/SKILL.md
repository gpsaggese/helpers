description: Check a file against applicable convention rules and list violations
model: opus
---

# Goal
- Find the violations of the rules that apply to the given file `<FILE>` and
  create a plan to fix them

# Workflow

## Select Rules
- If the user specifies a set of rules, apply those
- Otherwise, read `@.claude/rules.md`, which maps file types to rule sets
  - Find which `<RULE_FILE>` applies to `<FILE>`
  - Print it as
    ```text
    Rules: <RULE_FILE>
    ```

## Read Rules
- Read `<RULE_FILE>`
- Check its rules one by one on `<FILE>`
- List the unmet rules, ordered by importance and effort

## Save the Plan to File
- Do not implement any change. Create `<FILE>.plan.md` describing all the
  transformations needed to follow the rules, without changing the content or
  intention of `<FILE>`
- Say in the plan file how it was generated, with this line right after the title:
  ```markdown
  - Generated by `.claude/skills/skill.check_against_rules/SKILL.md`
  ```

# Verification
- [ ] `<FILE>` itself was not modified
- [ ] `<FILE>.plan.md` lists every violation found, ordered by importance and
      effort
- [ ] The plan does not change the content or intention of `<FILE>`
- [ ] The plan file says that it was generated by
      `.claude/skills/skill.check_against_rules/SKILL.md`
