# Goal

- **Input**: A `notebook_outline.<TAG>.md` outline file that describes each notebook
  cell (created via `.claude/skills/notebook.create_outline/SKILL.md`)
- **Outputs**:
  1. `.ipynb` file: Fully functional Jupyter notebook with working code,
     visualizations, and interactive widgets
  2. `.py` file: Paired with the `.ipynb` using `jupytext` in py:percent format
  3. `*_utils.py` file: Reusable helper functions for the notebook code
- **Purpose**: Implement the pedagogical design as an executable, interactive
  notebook
- Each visualization is a triplet of pre-viz markdown, a code cell, and post-viz
  markdown (see "Cell Structure in Notebook")

# Core Workflow

- **Understand the outline**: Review each cell's Purpose, Display, and (if present)
  Widgets and Guided Usage
- **Implement utility functions**: Write reusable widget and visualization code in
  `*_utils.py`
- **Create notebook cells**: Add markdown cells (context) and code cells (widget
  calls)
- **Follow the separation principle**: Utilities hold the implementation. The
  notebook holds only function calls

# Implementation Patterns

## Cell Structure in Notebook

- Each visualization in the outline becomes a sequence of cells (a triplet of
  stages, with more than one cell per stage):
  1. **Markdown cells (pre-viz)**: Goal, then Description split into Inputs and
     Panels
  2. **Code cell**: Visualization / interactive widget, with a comments panel
     that holds only variable state
  3. **Markdown cells (post-viz)**: Guided usage (one action per control plus the
     observation it produces, not general facts to learn), then Implementation,
     then the `print_obj_info()` code cell
- Follow `## Visualization Cell Triplet Details` in
  `.claude/skills/notebook.rules.md`
