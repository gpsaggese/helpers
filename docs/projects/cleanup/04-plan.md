# Cleanup Implementation Plan

- Generated by `.claude/skills/project.create_plan/SKILL.md`

## Goal

- Make `helpers` a general-purpose repo: drop the Causify and AWS specifics, move to
  `uv`, and clean up the repo root and the tooling
- Background:
  - What and why: [`01-prd.md`](/docs/projects/cleanup/01-prd.md)
  - How the dev system changes:
    [`02-design.architecture.md`](/docs/projects/cleanup/02-design.architecture.md)
  - The walkthrough that found the items:
    [#1465](https://github.com/gpsaggese/helpers/issues/1465)
  - GitHub project: [Cleanup](https://github.com/users/gpsaggese/projects/17)

## Plan Hierarchy

- This file is the source of truth of the plan, per
  [`D2`](/docs/projects/cleanup/03-decisions.md#d2-the-plan-file-is-the-source-of-truth)
  - It defines the themes, the versions, and the PRs
- [`07-progress.md`](/docs/projects/cleanup/07-progress.md): what is done and what
  was learned
- [`03-decisions.md`](/docs/projects/cleanup/03-decisions.md): why it is built this
  way
- `- [ ]` is an unmerged PR and `- [x]` is a merged PR
  - For a partly done PR, the entry says its status
- There is no execution plan yet: add one when several people work on the themes in
  parallel
- Verification commands of the whole project, from #1465:
  ```bash
  > git grep -i -l -E "causify|csfy|cryptokaizen|kaizen"
  > git grep -i -l poetry
  > git grep -l -E "s3_bucket_info|\becr\b|ECR"
  ```

## v0.1: Build Green

### `PR_B1`: [ ] Remove the AWS step from the CI workflows

- **Background**:
  - Four workflows run `aws-actions/configure-aws-credentials@v1`:
    - [`common_run_tests.yml`](/.github/workflows/common_run_tests.yml)
    - [`coverage_tests.yml`](/.github/workflows/coverage_tests.yml)
    - [`common_dev_image_build.yml`](/.github/workflows/common_dev_image_build.yml)
    - [`common_dev_image_release.yml`](/.github/workflows/common_dev_image_release.yml)
  - The step reads `vars.GH_ACTION_AWS_ROLE_ARN` and `vars.CSFY_AWS_DEFAULT_REGION`,
    which are not repo variables, and fails with
    `Input required and not supplied: aws-region`
  - The fast and slow tests fail on every run since 2026-11-02, and the coverage
    since 2026-11-01
  - The repo moved from the `causify-ai` org to `gpsaggese` on 2026-11-02, so CI now
    pulls `ghcr.io/gpsaggese/helpers:dev`, which does not exist
  - No test needs a real AWS account
  - See findings 1-4 of [`07-progress.md`](/docs/projects/cleanup/07-progress.md)
- **Before the PR**: the maintainer copies the current dev image to the GHCR of the
  repo owner, since no workflow can push it today (see `PR_B4`)
  ```bash
  > docker pull ghcr.io/causify-ai/helpers:dev-1.6.0
  > docker tag ghcr.io/causify-ai/helpers:dev-1.6.0 ghcr.io/gpsaggese/helpers:dev
  > docker tag ghcr.io/causify-ai/helpers:dev-1.6.0 ghcr.io/gpsaggese/helpers:dev-1.6.0
  > docker push ghcr.io/gpsaggese/helpers:dev
  > docker push ghcr.io/gpsaggese/helpers:dev-1.6.0
  ```
  - Then give the repo read access to the package in the package settings, or make
    the package public (component open question 1)
- **Changes**:
  - Delete the "Configure AWS credentials" step from the four workflows
  - Delete the `CSFY_AWS_*` env vars that the "Run tests" step passes to the tests
  - Delete the commented ECR login and ECR pull blocks
  - Drop `id-token: write`, which only the AWS OIDC login needs
- **Unit tests**: none, since the PR changes only workflows
  - Run the fast and slow workflows on the PR and compare with the last green run
    (2026-11-02: 4094 passed, 215 skipped, 168 deselected)
- **Result**: CI reports the real state of the tests
- **Acceptance**: the fast and slow workflows run past the AWS step and the image
  pull; each test that still fails has an issue
- **Requirements**: [`R1`](/docs/projects/cleanup/01-prd.md#r1-ci-runs-without-aws),
  [`R2`](/docs/projects/cleanup/01-prd.md#r2-ci-is-green-on-master)
- **Depends on**: none
- **Complexity**: low
